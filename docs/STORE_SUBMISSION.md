# App Store、应用宝和华为应用市场上架

## 通用材料

- 应用名称、副标题、分类、关键词和完整介绍。
- 1024×1024 图标、各尺寸手机截图、客服网站、隐私政策 URL。
- 企业主体证明、联系人、版权证明和软件著作权（中国大陆渠道通常需要）。
- 测试账号、审核说明、功能演示视频。
- 数据收集清单、第三方 SDK 清单、账号注销路径和隐私弹窗说明。
- 数字资产相关牌照、目标地区法律意见和产品不可用地区说明。

## App Store

1. 加入 Apple Developer Program，创建 App ID、证书和 App Store Profile。
2. 在 App Store Connect 创建应用、填写隐私问卷、年龄分级和出口合规。
3. Xcode Archive 上传构建，在 TestFlight 完成内部和外部测试。
4. 关联构建、提供审核账号和数字资产业务说明，提交审核。
5. 审核通过后手动、自动或分阶段发布。

涉及加密、钱包、交易或法币出金时，应提前确认 App Review Guidelines、当地牌照和金融服务资质。

## 腾讯应用宝

1. 注册腾讯开放平台企业账号并完成主体认证。
2. 创建移动应用，提交软件著作权、备案、隐私政策和行业资质。
3. 上传签名 AAB/APK、图标、截图和适配信息。
4. 完成隐私合规、安全检测和人工审核。
5. 审核通过后设置发布时间，并监控崩溃、ANR 和渠道反馈。

## 华为应用市场

1. 注册 AppGallery Connect 企业开发者并完成实名。
2. 创建应用、录入包名和签名证书指纹。
3. 上传 AAB/APK、内容分级、隐私信息、数据安全和行业资质。
4. 配置测试账号并提交审核。
5. 使用分阶段发布控制首发比例。

华为 Android 设备可发布标准 Android 包；HarmonyOS NEXT 不能直接运行该 Android React Native 工程，参见 `HARMONYOS.md`。

商店规则会更新，提交前必须重新核对各平台官方后台的最新要求。
